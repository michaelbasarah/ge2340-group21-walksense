Per-stop routine & wrap-up

At every stop
  • Stand still ~30s, phone held flat, same facing as the corridor
  • Record baro/mag (Phone A) & note the stop
  • On each walk, Phone B logs accel + gyro + mag together
  • Name the walk file From To (e.g. Sr11 Sr10)
  • Test day only: tick "here✓" on arrival
End of session
  • Stop recordings; export WiGLE full DB
  • Write the end time here: __________
  • Open WiGLE export — sanity-check it isn't empty
  • Back up all files before leaving the building
